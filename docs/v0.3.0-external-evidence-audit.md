## Security finding and correction

v0.3.0 checked `http://` and `https://` command arguments case-sensitively. An argument beginning with `HTTPS://` could reach an allow-listed executable rather than becoming `UNVERIFIABLE`.

v0.3.1 normalizes arguments before the prefix comparison and includes lower- and uppercase regression coverage. The immutable v0.3.0 release remains affected and should not be represented as containing this correction.

ACL remains not a sandbox. Executable-mode use on an external repository requires a disposable, least-privilege environment without secrets and with any needed network/filesystem isolation provided outside ACL.
