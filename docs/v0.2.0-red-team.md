## Security red team

Path traversal, Windows absolute paths, symlinks, disallowed executables, remote URL arguments, missing executables, invalid working directories, and command timeouts have automated tests. The remaining critical limitation is process isolation: an allow-listed command runs with the runner's permissions. The contract runner is not a sandbox.
