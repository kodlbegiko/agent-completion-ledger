# Expected report shape

```text
Task: minimal-documentation-task
Claimed status: completed
Ledger status: SUPPORTED
Evidence:
✓ readme-exists: README.md exists
✓ installation-heading: required text found
```

The real report also records tool version, repository commit, repository identity, contract path and SHA-256, trusted/static mode, report schema version, counts, and result digest. Exact digests and commit values depend on the target repository.
